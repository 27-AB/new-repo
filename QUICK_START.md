## 🎯 QUICK ACTIONS

### First Time Setup

1. **Seed Sample Data** (if needed):
   - Go to Research Projects → Click "Seed Sample Data" button
   - Go to Community Projects → Click "Seed Sample Data" button
   - This creates sample projects with milestones

2. **Create Your First Project**:
   - Login as Admin or Researcher
   - Go to Research or Community Projects
   - Click "+ Add Project" or "+ Add Research Proposal"
   - Fill in the form and save

3. **Add Milestones**:
   - Click "Milestones" button on any project
   - Click "+ Add Milestone"
   - Set title, deadline, priority
   - Save and track progress

4. **View Timeline**:
   - Click "Timeline" button on any project
   - See visual representation of project timeline
   - View all milestones on timeline

5. **View Gantt Chart**:
   - Go to Research or Community Projects
   - Click "Gantt & Timeline View" tab
   - See all projects in Gantt format

## 🔧 TROUBLESHOOTING

### If Frontend Doesn't Load
- Check if frontend is running on port 3001
- Open http://localhost:3001 in browser
- Clear browser cache and refresh

### If Login Fails
- Make sure auth-service is running on port 4004
- Check MongoDB connection
- Verify credentials are correct

### If Data Doesn't Load
- Make sure all backend services are running
- Check MongoDB connection for all services
- Look for errors in service terminals

### If Charts Are Empty
- Seed sample data first
- Create some projects manually
- Refresh the dashboard page
